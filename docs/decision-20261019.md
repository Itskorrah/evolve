# Decision record — 19 October 2026

Baseline: main `89e0b5d`, six installed skills, managed checksum installer,
ledger, benchmark tool and one Basket trial. The latest prior main CI matrix
was successful. No new release or universal host certification is established.

## Chosen scope and acceptance

1. Add `verify` read-only integrity/source-drift reporting rather than a new
   installer framework. Backwards-compatible version-1 manifests are still accepted.
2. Protect managed writes against Windows reparse points, including Python
   3.10/3.11 which lack `Path.is_junction`.
3. Add four isolated synthetic agent reference tasks and matched-trial reporting.
   Comparing reported trials is not proof of causal model quality improvements.
4. Explicitly separate documented native discovery paths, manual file loading,
   automated Python checks and live host acceptance.
5. Require final-head CI success; no automatic merge, deploy or billing.

## Constraints

No third-party runtime dependencies, no unreviewed install scripts or account
changes. Keep existing licences, local edits, user-owned delivery permission and
a clear distinction between executed tests and written assertions.
