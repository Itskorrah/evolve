# Example requests

Use these in the agent, while working in the target application. Adjust scope and
delivery permission. The names invoke skills; they are not shell commands.

## General improvement

```text
Use $evolve to improve this application. Establish the actual baseline, investigate
correctness, performance, usability and maintainability, then implement complete
high-value improvements. Use independent review when available. Continue through
the next eligible task while the run allows. Keep changes local and record the
evidence and exact next action.
```

## Full GitHub delivery

```text
Use $evolve on this repository. Focus on reliability and product quality. You may
commit, push branches, create PRs and merge verified changes into main in owner/repo.
Respect required checks and protections. Preserve user changes and licences. Keep
working through useful improvements; report actual merge results and blockers.
```

## Audit only

```text
Use $evolve-audit for a deep audit. Trace critical workflows, verify findings and
rank substantial opportunities. Show coverage and limits. Do not implement changes,
publish findings or alter the application.
```

## Measured performance

```text
Use $evolve to improve slow loading and scrolling. Reproduce the user workloads,
profile the bottlenecks, implement fixes and measure comparable before/after runs.
Preserve output and interaction correctness. Do not claim a speedup without evidence.
```

## Product design

```text
Use $evolve-design to improve navigation and keyboard usability. Capture and inspect
the current interface, implement a coherent change using the existing design system,
and verify real interactions and relevant themes. Keep existing capabilities working.
```

## Resume

```text
Use $evolve to resume this application. Reconcile saved state with the current
revision, reassess stale evidence, preserve other contributors' changes and continue
the next eligible task. Apply only the delivery permission authorised in this task.
```

Evolve can operate with different tools and agent hosts. Replace `$skill-name` with
your host's invocation or explicitly load the matching `SKILL.md`.
