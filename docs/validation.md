# Validation record

Recorded on **14 October 2026** for the initial Evolve pack.

## Package and tools

- Package validator: six skills, valid metadata, portable references and helper syntax.
- Local helper/installer suite: **60 tests passed** on macOS with Python **3.12.14**,
  including a run with resource warnings treated as errors.
- Vercel Skills CLI local discovery: all six skills discovered using `add --list`;
  no installation into the user's agent directories was performed.
- Installed-tool integration: a temporary project completed a task through the
  copied coordinator tools, including paths containing spaces.

Independent package review reproduced five issues in the initial implementation:
submodule freshness, overlapping evidence attempts, concurrent installer ownership,
benchmark machine identity, and malformed state handling. They were repaired and
covered by targeted regression checks in the passing suite. Executable modes and
parent-directory symlink handling were also strengthened.

The first remote matrix passed on Linux and macOS and exposed a Windows rooted-path
validation defect. Explicit cross-platform path checks and three additional
regressions repair that case; the complete local suite passes after the change.

## Live workflow trial

A fresh agent loaded the coordinator and worked in an isolated synthetic Basket
application generated by the evaluation fixture. Its task authorised local
improvements and meaningful regression coverage, with no external delivery.

The resulting application implements three completed improvements:

1. Order totals apply each item quantity.
2. CSV import accepts genuinely blank lines while preserving valid field content.
3. Malformed CSV records, invalid numbers and non-finite prices produce useful
   line-specific errors without returning a partial successful import.

The trial recorded failing-before and passing-after checks. The supervisor inspected
the actual diff, re-ran **24 application tests**, and reconciled the final ledger:
no active tasks and no completed tasks with stale evidence. Changes remained local.

The host usage limit interrupted the agent's final report after these artifacts
were produced. The record above is based on inspected files and re-executed checks,
not an assumed successful agent message. A helper snapshot algorithm update during
the trial triggered revalidation; final recorded checks match the current source.

## Limits

This is one small Python application trial. It does not establish live performance,
UI/accessibility, migration, complex compatibility or GitHub delivery behaviour of
the skill across all products and agent hosts. Audit-only and resume scenarios are
provided for future live evaluations; their existence is not a passing result.

The CI matrix is configured for Linux, macOS and Windows on Python 3.10/3.13.
Actual remote results are visible in [GitHub Actions](https://github.com/Itskorrah/evolve/actions).
Package/tool checks and this trial are separate from host certification or a
guarantee that any application can be fully improved in one run.
